### Stress Test Results

| --- | --- | --- | --- |
| **December Year Crossing** | `2026-12` sale -> `2027-01-25` 1st inst | `2027-01-25` & `2027-02-25` generated | ✅ PASS |

| **HMAC-SHA256 Hash Validation** | Re-computed signature matches DB | 19/19 DB receipts match exact signature | ✅ PASS |
| **Mismatched Item Sum Payload** | API rejects `HTTP 400` | API creates receipt (`HTTP 201`) | ⚠️ OBSERVED |
| **Mismatched Installment Sum Payload** | API rejects `HTTP 400` | API creates receipt (`HTTP 201`) | ⚠️ OBSERVED |

### Recommended Defense / Mitigation
Add `validate()` method to `ReceiptSerializer` in `backend/api/serializers.py`:
```python
def validate(self, attrs):
    # Enforce total_amount == sum(sale_items)
    items = attrs.get('sale_items', [])
    if items:
        calculated_total = sum(item['quantity'] * item['unit_price'] for item in items)
        if attrs.get('total_amount') and Decimal(str(attrs['total_amount'])) != Decimal(str(calculated_total)):
            raise serializers.ValidationError({"total_amount": "إجمالي الفاتورة لا يطابق مجموع الأصناف."})

    # Enforce down_payment + sum(installments) == total_amount for installment sales
    if not attrs.get('is_cash_sale', False):
        down_pmt = Decimal(str(attrs.get('down_payment', 0)))
        total_amt = Decimal(str(attrs.get('total_amount', 0)))
        installments = attrs.get('installment_payments', [])
        inst_sum = sum(Decimal(str(inst['amount'])) for inst in installments)
        if down_pmt + inst_sum != total_amt:
            raise serializers.ValidationError({"installment_payments": "مجموع المقدم والأقساط لا يطابق إجمالي الفاتورة."})
    return attrs
```
