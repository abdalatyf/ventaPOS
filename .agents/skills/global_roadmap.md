# VentaPOS Development Roadmap

As the Lead Architect and Project Manager, I have documented our agreed-upon high-level strategy for completing the VentaPOS ecosystem.

## Strategic Decision
We have decided to prioritize **Phase 1 (Complete the Offline Loop)** to ensure that the core operational flow between Mobile salespeople and the local Desktop branches is perfectly seamless and independent of internet connectivity.

---

### ⏳ Phase 1: Complete the Offline Loop (On Hold)
**Goal:** Finalize the Air-Gapped Sync between Mobile and Desktop.

*   **Architectural Design:** Outline the exact data parsing flow for the Desktop application to ingest the `Sales_B{...}.json` files generated by the Mobile app.
*   **Conflict Resolution Strategy:** Design the business logic for how the Desktop SQLite database will handle duplicate receipt numbers or outdated inventory syncs.
*   **Agent Assignment:** Once ready to begin, the `Desktop Agent` will be assigned to write the ingestion scripts based on this design.

### 📋 Phase 2: The Central Server (Future)
**Goal:** Build the online option for multi-branch data centralization.

*   **Architectural Design:** Outline the REST API endpoints and payload structures for the Server backend.
*   **Security Design:** Finalize the Gatekeeper pattern using `machine_id` hardware footprints to authenticate sync pushes from Desktop clients.
*   **Agent Assignment:** The `Server Agent` will be assigned to build out the Django endpoints and database models.
