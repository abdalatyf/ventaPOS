# Promo App - API & Security

## Overview
The `Promo` application (`D:\Projects\VentaPOS\Promo`) is a static HTML page. It does not contain an API server, nor does it consume any REST/GraphQL APIs.

## Data Exchange & Network Calls
- **Consumed APIs**: None.
- **Exposed APIs**: None.
- External links are used to direct users to WhatsApp for communication: `https://wa.me/201044208010`. These links occasionally include pre-filled text parameters via query strings (e.g., `?text=عايز%20أعرف...`).

## Security Configurations & Cryptography
- **Authentication Flow**: None.
- **Headers & Middleware**: Not applicable.
- **Cryptographic Functions**: None.
- **Permissions / Restrictions**: The site itself requires no authentication. Security claims mentioned on the landing page (e.g., encryption, offline capability, device binding) relate to the downloadable VentaPOS desktop application, not the promotional website itself.
