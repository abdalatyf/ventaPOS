# Application Deployment Skill

## Overview
This skill dynamically loads the deployment instructions for the DevOps Agent, keeping the main context window clean. It enforces the Merging and Deployment Gate.

## Workflow

### 1. Pre-Deployment Audit
- Read the Security Audit Report generated by the Security Agent.
- Read the QA Walkthrough and test coverage reports.
- Ensure all tests pass 100% and no critical vulnerabilities exist.

### 2. Local Testing Only
- **CRITICAL**: The human architect has explicitly disabled remote deployments for now. Do NOT use Docker, VPS, or remote servers.
- Execute the application EXCLUSIVELY on `localhost` (127.0.0.1) for testing.
- Ensure the Waitress server runs locally and the Flutter app is tested on a local emulator/device.

### 3. Deployment Interception
- **CRITICAL:** When attempting to run Waitress locally or test Flutter, ensure the ports do not conflict.
- The `merging_and_deployment_gate` applies only if you attempt to push code or change the local infrastructure.
